# Automated author-style evaluation

Status: exploratory. This protocol requires no human blinded ratings. It measures whether generated text approaches a target writer's measured profile more than a rival's on identical content. It cannot certify recognizable author voice.

1. Collect at least three independent reviewed papers per anonymous writer; use two for development and the third for a whole-paper attribution diagnostic. Match genre, section, topic and publication period across writers where possible, and verify the primary drafting contribution. Keep sources and outputs outside Git.
2. Freeze content briefs, model/version, prompts and scoring rules. For each brief, generate a baseline and a target-guided draft for every writer. Use the identical baseline for both writers. A generic academic draft may serve as a separate baseline. Record prompts and exact outputs privately.
3. Save a JSON object with `cases`: each entry needs `case_id`, `content_id`, anonymous `author_id`, `model`, `section="discussion"`, `baseline` and `guided`. Each content item must have exactly one case per writer with the same model, section and exact baseline. Inputs need at least two content items and each draft at least 50 measurable words.
4. Run `pentwin auto-eval SIX_PAPERS.json GENERATED_CASES.json`. The command validates independent sources, reuses the existing leave-one-paper-out diagnostic, and reports per-writer paired margins. Positive margin means closer to the target profile than the rival; positive guided-minus-baseline means movement toward the target. Report both, including failures.
5. Inspect raw `length` and `seven` feature scores and the `sentence_only` and `short_passage` comparisons. Whole-paper paragraph length is poorly matched to a short draft; the short-passage metric omits it. This metric was introduced after inspecting the first pilot, so its pilot result is exploratory. Length-only is a strong comparator, not an author-identity guarantee.
6. Re-run on new writers, matched time/topic and genuine research manuscript sections, with frozen scoring and independently sampled GPT/Claude calls. Report writer-level results and compare generic academic prose. Do not use the six inspected papers as untouched confirmation data.

The first six generated texts were written within the assistant session after reading aggregate profile values; they were not separate API calls to GPT and Claude. This makes the experiment an instrument and feasibility check, not an independent effectiveness estimate. The PenTwin evaluation does not examine scientific meaning or citations.

# Author-style evaluation protocol

Status: the blind rating machinery is implemented; no generated author-likeness result has been established. A source is eligible only after checking the extraction and confirming the target writer's primary contribution. Keep a paper-family holdout untouched while developing the profile and prompt.

1. Collect at least three independent papers per target writer, with two development families and a whole family held out. Review extraction, section, genre, writing role, and any editorial intervention. For an author-specific claim, recruit multiple writers and match topic, period, journal, and section as closely as possible. Log confounds anonymously.
2. Fix a shared content brief for each test case, a model/version and settings, and the section. Generate ordinary GPT/Claude, generic academic, and PenTwin-guided texts in separate calls without access to the held-out paper. Compare ordinary versus generic and generic versus PenTwin in separate pairwise runs. Record prompts, profile digest, tool invocations and output hashes privately. No raw paper exemplar leaves the local corpus.
3. Create a private JSON file with `cases`: `case_id`, anonymous `author_id`, `model`, `section`, `baseline`, and `guided`. Run `pentwin blind INPUT.json OUTPUT --seed PRIVATE_SEED`. Each pair is shuffled independently; the rating CSV contains text and an anonymous target author label but does not contain which side was guided. Keep `private_key.json` away from raters. Never commit drafts or the key to the public repository.
4. A rater familiar with the target writer scores each masked draft on 1–5 scales: `likeness` (1 = unlike this writer; 5 = strongly characteristic), `distinctiveness` (1 = generic academic prose; 5 = recognizable individual habits), and `naturalness` (1 = awkward; 5 = fluent). They choose `preferred=A/B/tie` for the closer writer voice and can explain the choice in `comments`. Use independent raters where feasible and preserve disagreements rather than resolving them from the key.
5. Run `pentwin ratings OUTPUT` after filling every rating. Report preference counts by anonymous author and model, paired wins/ties and ordinal differences. Count author clusters, not repeated passages, as independent evidence. Predefine ties and missing ratings; this tool rejects missing ratings and altered text or author provenance. A profile distance is a diagnostic, never the outcome measure.
6. Inspect performance against both ordinary and generic academic controls on new writers and sections. A successful style claim requires repeated blinded preference for PenTwin across writers, not merely a pooled result or improvement in sentence length. If results differ across writers, report that heterogeneity. The earlier six-paper 5/6 attribution result is exploratory and is not a generated-text benchmark.

The PenTwin rating tool does not assess scientific claims, citations, or meaning. Those checks belong to an independently chosen service in the surrounding workflow.

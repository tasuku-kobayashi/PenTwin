# Paper-grounded logic and calibration (2026-10-26)

**Historical calibration:** the first-seven-sentence results below have been superseded by the [200-word axis-matched protocol](AXIS_MATRIX_AND_OA_VALIDATION.md). They are retained to explain the design history, not current evaluator eligibility.

## Literature boundary

The design basis is [Wang et al. (2025)](https://aclanthology.org/2025.findings-emnlp.532/) and papers **directly cited in its reference list**: [Bhandarkar et al. (2024)](https://aclanthology.org/2024.personalize-1.6/) and [Cho et al. (2025)](https://aclanthology.org/2025.naacl-findings.326.pdf). The latter two provide context for prompt-only emulation and iterative negative-example explanations. No unverified citing work informs this implementation. Previous PenTwin experiments are auxiliary observations, not literature evidence.

Wang et al. split each author's human samples into prompt examples and test samples, compare zero-shot and five-shot generation with matched content, and use attribution, verification and stylistic distributions. Their example-selection ablation does **not** show that selecting only topically similar or length-matched examples reliably improves style. Bhandarkar et al. also find limitations in off-the-shelf prompt emulation. Cho et al. report gains from trial/error/explanation, but their evaluation includes an LLM judge; those gains cannot be imported as PenTwin accuracy.

## Hypotheses and decisions fixed before this run

1. **Human identifiability first.** A useful style proxy should assign unseen human text to its author in a matched genre. A simple 5/6 with at least 2/3 per author is a **descriptive operational screen only** on six papers, not a validated accuracy threshold or statistical significance. Failure makes generated scores `calibration_inadequate`; passing only allows exploratory comparison. The pre-existing 5/6 length-only result cannot establish personal voice.
2. **Independent diagnostics may disagree.** A withheld function-word set and a separate surface-structure set should be reported separately. The function set is not exposed as rewrite instructions. Structure includes sentence length, so success there may reflect formatting, time or journal. A guided draft improves a metric only if its rival-minus-own distance increases against the same-content baseline. Disagreement blocks a positive conclusion.
3. **Few-shot exemplars are a candidate, not a proven PenTwin feature.** Wang et al. tested actual author samples. PenTwin's model-facing MCP responses contain no source passages, so the present card is an indirect substitute and its benefit must be compared with zero-shot and, where genuinely authorized and available, actual examples in a separate controlled experiment. Two development papers and one holdout meet the product's three-paper minimum; they do not reproduce Wang et al.'s five-shot setting. More examples and topical matching are not presumed better.
4. **Iterative critique is an unconfirmed candidate.** Cho et al.'s trial/error/explain suggests comparing a draft and an error explanation, but the existing card critique is not TICL. Test it against a single-pass card only after the evaluation cohort and protocol are frozen.

Scientific content assessment is outside this style experiment, as requested. Matching the same content brief is an experimental control, not a claim to verify its truth. AI-text detection is excluded from the success rule: it measures a different property and Wang et al. discuss detector bias.

## Implementation

Run `pentwin paper-eval PRIVATE_MANIFEST.json [PRIVATE_CASES.json]` locally. The manifest format and six-paper independence checks are those of `pentwin diagnose`: two anonymous authors, three independent paper files each, one stratum. For each paper, measure the first seven valid sentences (minimum 50 words). Leave one entire paper out per author, compare it with profiles from the other two papers for each author, and report six human attribution margins. For optional generations, profiles use only the first two papers per author; the third remains a holdout. A case has the same fields and matched-content controls as `auto-eval`. The command returns aggregate numbers and anonymous IDs, never source text, source paths or draft text. It is an approximation of Wang et al.'s evaluation, **not** their trained AA/AV or LIWC/WritePrint implementation.

The initial MCP `generation_protocol` compared generic, card and critique conditions. The current version replaces that exploratory layout with a factorial set of lexical, ending and order axes plus an optional separately supplied target opening. It never draws an opening from the sealed corpus. See the [current protocol](QUALIFIED_GENERATION_EXPERIMENT.md). The earlier critique idea was inspired by Cho et al.; it was not their negative-sample TICL method and has no demonstrated PenTwin benefit.

The old `diagnose`, `auto-eval`, `heldout-axes`, and exploratory cards remain available as historical probes. Their scores do not enter the paper-grounded screen. Fixed dictionaries and scales in the new proxy are engineering choices that need external validation.

## Private pilot, exploratory only

The previously inspected matched cohort has two anonymous writers and three short same-column texts each. Both function words and surface structure identify 5/6 held-out human windows (3/3 for one writer, 2/3 for the other). Existing six guided drafts across three content briefs improve 3/6 on each metric; function words improve for the second writer only, structure for the first writer only. Thus the two metrics disagree on which writer benefits, and no consistent author-style gain is demonstrated. Earlier drafts were assembled in-session around numerical guidance, not sampled independently from GPT/Claude with the present protocol. The cohort has unverified primary drafting roles, no cross-writer topic overlap and nonoverlapping publication periods; its holdouts were already inspected during development. Neither this result nor 5/6 human discrimination confirms authorship or recognizable style.

A second previously assembled six-paper cohort was run as a robustness check after the implementation was frozen. Function words identified 5/6 human windows (2/3 and 3/3), whereas surface structure identified only 2/6 (1/3 for each writer). No generated drafts were evaluated for this cohort. Its confound metadata is incomplete and it is not a new untouched confirmation set. The metric disagreement is a concrete reason to refrain from promoting either 5/6 score into an author-likeness claim.

The next confirmation requires a new matched cohort, frozen feature definitions, several independent drafts per content brief under zero-shot versus card guidance, the same host model and decoding settings, and per-writer reporting. If actual author examples become available for model-facing use, compare that condition separately and keep all source text private. No human blinded rating is required.

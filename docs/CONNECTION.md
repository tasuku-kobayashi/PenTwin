# Connection checklist (Windows pilot)

1. Install Python 3.11+ and PenTwin in a private local environment. Create and visually review a run, then `seal` it. Use an absolute private path to that run. Do not place the corpus in Git.
2. Run `python -m pentwin.cli serve C:\private\pentwin\run-001` as a local stdio process. Its stdout is reserved for MCP JSON-RPC. Test `initialize`/discovery, `tools/list`, `corpus_status`, `style_profile`, `rewrite_plan`, `assess_revision` using a protocol client and synthetic documents first.
3. For Claude Code, register the stdio command using `claude mcp add --transport stdio pentwin -- python -m pentwin.cli serve C:\private\pentwin\run-001`, then use `/mcp` to check connection and a synthetic prompt to verify an actual tool call. Claude Desktop uses local MCP extensions; package and install one before claiming desktop support. These are separate configurations.
4. For ChatGPT Desktop, a local stdio plugin has separate submission and allowlist requirements. The alternative private Secure MCP Tunnel can forward to stdio but needs a Platform tunnel, API key, the correct workspace association, permissions, and outbound HTTPS. Configure it only for a private run whose model-facing passages may be sent to ChatGPT. Check actual tool discovery and invocation in the intended desktop thread.
5. Record OS, client version, account/workspace, SDK and server version, transport, tool list, invocation result, and whether source text leaves the host. A successful SDK handshake proves the server protocol path, not client installation or model compliance. Recheck after client or model updates.

Official references: [OpenAI desktop-only plugin requirements](https://developers.openai.com/plugins/deploy/desktop-only), [Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels), [Claude Code local MCP](https://code.claude.com/docs/en/mcp-quickstart), [Claude Desktop extensions](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop), [official Python MCP SDK](https://github.com/modelcontextprotocol/python-sdk).

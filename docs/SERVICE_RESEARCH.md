# Writing-naturalness services: design choices for PenTwin (2026-10-26)

This is a comparison of publicly documented product features, not a performance benchmark or endorsement. No pilot writer, document, or private paper was sent to any service.

| Product and primary documentation | Observed feature | PenTwin decision |
| --- | --- | --- |
| [Grammarly voice profile](https://support.grammarly.com/hc/en-us/articles/23153676821773-View-and-customize-your-voice-profile) | Separates longer documents from messages and lets a writer inspect and remove detected voice elements. | Consider a human-editable, section-scoped profile. A profile is useful only if blinded outputs and fidelity tests support it. |
| [QuillBot Fluency and Academic modes](https://help.quillbot.com/hc/en-us/articles/35854318883351-What-are-modes-in-the-Quillbot-Paraphraser-and-how-do-I-use-them) | Fluency aims to make few changes; Academic aims for a research tone. | Use minimal-edit guidance and a generic academic rewrite as separate controls. |
| [QuillBot Freeze Words](https://help.quillbot.com/hc/en-us/articles/35855113357847-What-is-Freeze-Words-in-Quillbot) | A user can hold words/phrases fixed in supported modes; the product does not support special characters and dashes in this feature. | Implement optional *exact* protected spans, including numbers, units, comparison phrases, negation and citation tokens. Check counts after rewriting. This catches only literal changes, not altered relationships or meaning. |
| [Jenni Reviews](https://docs.jenni.ai/docs/ai-tools/reviews/) | Tone of Voice checks word choice, sentence structure, formality, clarity and readability; a PDF can be a style reference. | Evaluate these dimensions separately. PenTwin's source corpus remains local; this is not a proposal to upload private PDFs to Jenni. |
| [Paperpal paraphrasing](https://paperpal.com/blog/academic-writing-guides/frequently-asked-questions-paraphrasing) and [Writefull for Word](https://help.writefull.com/writefull-for-word--user-guide) | Academic language and editing assistance. | Use generic scholarly editing as a comparison condition; marketing claims cannot establish author-specific resemblance. |
| [Undetectable AI API](https://help.undetectable.ai/en/article/humanization-api-v2-p28b2n/) | Optimizes a rewrite toward detector-oriented humanization. | Reject detector scores and detector evasion as PenTwin objectives. They do not test a specific researcher's voice or scientific fidelity. |

The apparent shared idea is a controllable revision process: a reviewer can see style tendencies, preserve selected scientific spans, make restrained changes, and inspect the result. None of the linked product documentation independently validates its combination of author likeness and unchanged life-sciences claims. In the planned same-facts experiment, compare ordinary GPT/Claude writing, generic academic editing, and PenTwin guidance; rate author likeness, naturalness, and scientific fidelity separately. An output that merely looks less formulaic is not sufficient.

The optional PenTwin `protected_spans` input is literal, case-sensitive and checked against the original and revised drafts. It does not stop the host model from generating a changed sentence, and identical counts do not prove that a comparison, negation or citation still relates to the same claim. Every output still requires review.

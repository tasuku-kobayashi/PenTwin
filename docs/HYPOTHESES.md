# Author-style hypotheses and decision record (2026-10-26)

The product objective is a more author-like **generated English life-sciences passage** with unchanged scientific meaning. Identifying the author of an existing article is a useful intermediate check, not the objective itself. The six-article exploratory corpus has already influenced design decisions and must not be used for an independent release claim. No participant identity, source passage, or private corpus belongs in this repository.

Before further implementation or validation, use the claim ladder, confound analysis and prospective decision rules in [the theory record](THEORY_BEFORE_VALIDATION.md). The 5/6 same-column result is an exploration signal, not a product threshold.

| Hypothesis | Current evidence | Next discriminating experiment | Current confidence |
| --- | --- | --- | --- |
| H1: seven surface features omit useful author signals | First inspected cohort: seven features 4/6, function words 6/6. Second cohort: seven features 6/6, function words 4/6. Third cohort in the same journal column: seven features 5/6, function words 3/6, length-only 5/6. The apparent feature gain did not replicate over length. | Test in matched-genre research manuscripts, with pre-frozen features and whole-paper holdouts. | Function-word-only hypothesis weakened; author-specific signal unproven. |
| H2: genre, journal, section and topic shifts masquerade as author differences | The second cohort's 6/6 separated two different named columns. In the third, same-column 2020 cohort, seven features scored 5/6, identical to length-only. This reduces the column confound, but author, time and topic still covary. | Enroll enough independent articles for at least two reference families and one held-out family in *each* matched genre/section stratum. Cross topic and journal in a separate test; report every stratum. | Column confounding remains plausible; incremental author signal was not found in this small matched-column check. |
| H3: profile-to-instruction conversion is too generic | Shared prioritized instructions: 3/4 in the inspected cohort, 2/4 in the new cohort. No LLM output was produced. | Hold source facts, model/version and section fixed. Randomize ordinary vs guided outputs; keep tool logs and hashes; blind rate author likeness. Include a no-profile generic-academic guidance control. | Plausible; generated-text effect unknown. |
| H4: proxy scores fail to track likeness or factual correctness | No generated output has been rated. Style distance only measures the chosen features. | Rate author likeness, naturalness and factual fidelity independently. Report paired wins and material-error cases. Test agreement of each automated metric with blinded ratings without selecting the metric on the evaluation set. | The measurement gap is certain; the direction of bias is unknown. |

## Iteration outcomes

1. Added fixed function-word and discourse-cue aggregate features to the local engine, with no source text or rare lexical sequences in MCP output. They are exploratory diagnostic features, and the host LLM receives only aggregates.
2. Re-ran whole-paper leave-one-out comparisons on the already inspected six-article corpus. The function-word result improved from the old 4/6 to 6/6, but a single high-frequency word contributes materially and no independent replication exists. Rhetorical cues alone gave no improvement. The new plan still shared 3/4 instructions across the two profiles.
3. Extended the private blind-rating workflow with separate paired dimensions and a material-error gate. Synthetic tests exercise the gate. This is an implementation check, not human or model-generated quality evidence.
4. Added an optional human-reviewed rhetorical-move filter and stopped automatic all-section fallback when a requested section or move lacks two independent development families. Synthetic tests and the MCP SDK integration pass. This reduces a known genre/section mismatch risk, but does not establish a likeness gain.
5. Sourced a second, disjoint set of two sole-author medical columns (three articles each, 2012–2017) from one journal, with bodies manually delimited before signatures and references. Whole-article leave-one-out using two other articles per author gave length-only 5/6, seven features 6/6, seven plus rhetorical cues 6/6, fixed function words 4/6, combined 6/6. Each author wrote a *different recurring column*, so this is a column-confounded stress test, not matched-genre research-manuscript validation. On the same fixed fact draft, plans shared 2/4 top instructions. The source texts and identities remain outside Git.
6. Because function-word-only accuracy fell from 6/6 to 4/6 in the new cohort, MCP `rewrite_plan` and `style_profile` now exclude function-word rates from model-facing output. The local `aggregate` function remains available for offline diagnostic study. The automatic rewrite never treats this feature set as a validated author signal.
7. Tested a third, different two-author cohort in the *same named editorial column* of the same medical journal: three sole-author articles per writer from 2020, bodies isolated from signatures, publisher masthead, references and a substantial third-party quotation. The pre-existing feature sets yielded length-only 5/6 (2/3, 3/3 by author), seven features 5/6 (2/3, 3/3), seven plus rhetorical cues 5/6, and fixed function words 3/6 (2/3, 1/3). Holding out each article while comparing the two remaining articles per writer adds no measured gain over length. One article explicitly marks an editor transition and was trimmed at that personal sign-off. Chronology and topics are not matched, the article body includes other short quotations, and extraction artifacts may persist. This is an exploratory stress test of attribution, not an independent estimate of generated style quality. Names and source passages remain private.
8. Added `pentwin diagnose` for a private six-paper matched-stratum manifest. It checks independent files and duplicate bodies, holds out whole papers, gives each paper one vote, reports per-author scores and the difference over a length-only comparator. Synthetic tests and the third private cohort exercise the command. It never exposes source text, paths or digests in its output; the user must review extraction, authorship and confounds.
9. Extended the diagnostic with paired wins/losses against length and optional publication-month, topic, journal, genre, section and confirmed-primary-drafter metadata. The inspected same-column cohort had zero paper-level gains or losses for seven features versus length, and its two writers occupied nonoverlapping publication periods and separately labeled topics. Sole bylines were not treated as verified original-draft roles. These are reported as design risks, without changing the exploratory 5/6.
10. Reviewed documented [writing-naturalness services](SERVICE_RESEARCH.md). Added optional exact protected spans and minimal-edit guidance, verified by synthetic tests and MCP stdio calls. Literal span counts are alarms rather than a meaning guarantee. Generic academic rewriting becomes an explicit future comparator; optimizing an AI-detector score was rejected as a product objective.

## Pre-registered next-stage decision rule

Before collecting new articles, freeze code and extraction rules; keep at least three independent papers per author, with two for development and a whole paper held out. Require enough papers per matched stratum before making section/genre claims. Compare against length-only and generic-academic controls, and report per-author outcomes rather than one pooled score. For actual same-content drafts, require a blinded improvement in likeness across authors and sections without increased material factual errors or naturalness regressions. A small pilot yields descriptive evidence, not a universal accuracy rate. If matched-stratum recognition improves but blinded drafts do not, prioritize H3; if recognition fails under controls, revisit H1/H2 before editing prompts.

## Research basis

- Altakrori et al., [Topic Confusion Task](https://aclanthology.org/2021.findings-emnlp.359/): topic shifts can confound author attribution; POS-based stylometry was relatively robust in their evaluation.
- Sundararajan and Woodard, [What represents style?](https://aclanthology.org/C18-1238/): syntactic and lexical evidence behave differently across topic and genre.
- Sawatphol et al., [Topic Leakage](https://aclanthology.org/2024.tacl-1.75/): apparent cross-topic evaluation can still leak topic shortcuts.
- Alliheedi et al., [Rhetorical Moves in Biochemistry Articles](https://aclanthology.org/W19-4514/): scientific argument structure is a meaningful annotation target.
- Horvitz et al., [TinyStyler](https://aclanthology.org/2024.findings-emnlp.781/): few-shot author style transfer is possible in their evaluated domains, without establishing performance on this product's life-sciences papers.
- Pauli et al., [Mind the Style Gap](https://aclanthology.org/2025.findings-emnlp.1175/): content-preservation metrics can appear better than they are when evaluation sets are too easy.
